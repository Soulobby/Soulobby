# Soulobby

This is the Soulobby application that powers the [Discord server]!

## Development

> [!IMPORTANT]  
> This repository must always use the development version of [discord.js](https://github.com/discordjs/discord.js). Stable versions are not to be used.

We always use the development version of discord.js to ensure things over there are looking nice and calm. Don't worry, our developers are too awesome to let any issues happen to our application.

If you find there are issues, please do not hesitate to open an issue or speak up in the [Discord server]!

[Discord server]: https://discord.gg/7zYR8bnJJK
